# ml-project-premium-prediction
Health insurance prediction project (Regression)

Developed a regression model to predict healthcare insurance premiums using customer profiles. Achieved 98% R² accuracy with Linear Regression and XGBoost. Deployed a real-time Streamlit app after data cleaning, EDA, and model tuning.

Objective: Predicted insurance premium amounts using regression models, based on customer demographics and policy details, to help insurers make data-driven pricing decisions

Data Prep: Cleaned and preprocessed historical insurance data with Pandas and NumPy. Conducted exploratory data analysis (EDA) to uncover feature correlations and trends affecting premium values.

Modeling: Trained and compared Linear Regression and XGBoost models. Applied hyperparameter tuning techniques to enhance model performance and ensure reliable, generalizable results.

Deployment: Achieved a 98% R² score. Built and deployed a Streamlit web app for real-time premium prediction, allowing users to interactively explore model outcomes.
